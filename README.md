# setup-mac

Richtet mein "Zentrales Gehirn" auf einem Mac mit einem Befehl ein.

Terminal oeffnen und eingeben:

```
curl -fsSL https://raw.githubusercontent.com/derspassvogel911/setup-mac/main/install.sh | bash
```

Installiert: Homebrew, Git, GitHub CLI, Node.js, Obsidian, defuddle, knap, Claude Code, holt den privaten Vault und die Obsidian-Plugins.
Die Anmeldung bei GitHub passiert im Browser. Das Skript enthaelt keine Zugangsdaten.
